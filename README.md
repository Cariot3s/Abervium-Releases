# Abervium · versiones públicas

Canal público de descargas de **Abervium**, un juego incremental para Android (vertical).

- Descargas: sección **Releases** de este repositorio.
- `latest.json`: feed que el propio juego consulta desde *Ajustes > Comprobar actualizaciones*. Solo se actualiza después de que la APK de la Release esté publicada y verificada.

Instala encima de la versión anterior; Android pedirá permiso para instalar desde esta fuente. La alpha 0.2.5 y anteriores usaban otra firma: desinstálalas una vez antes de instalar la 0.3.0-alpha.

El código fuente es privado. Este repositorio solo contiene versiones publicadas.
